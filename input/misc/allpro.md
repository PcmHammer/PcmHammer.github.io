If you're using an AllPro adapter, you'll want the latest firmware, which at the moment is version 1.21.  Devices shipped after June 2018 will have this version already installed, but older devices may need to be updated. 

Update instructions are available here:

http://www.obddiag.net/allpro_prog.html

And the latest firmware is available here, from the manufacturer:

http://www.obddiag.net/allpro/allpro-hex.zip
