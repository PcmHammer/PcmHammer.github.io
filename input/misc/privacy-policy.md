When PCM Hammer starts up, it will fetch an updated help file and a welcome message from GitHub. No personal information is sent in the request.

The help-file request is done in order to provide users with updated content.

The welcome-message request is done so that if the community finds a bug or other important information that users should know, we can display that information to all users at startup time. We also use the welcome message to inform users when new versions are available. This software was written by volunteers, and we're testing it as we go. We can't promise that every release will be perfect. But we want everyone to be using the latest version, and we want to be able to warn people if we find a serious problem.

Other than that, PCM Hammer does not send any information from your PC.
